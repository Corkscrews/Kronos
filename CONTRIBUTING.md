## Contributing

1. Fork the repo.
1. Run the tests with `make test` (`swift test --disable-swift-testing`).
1. Lint with SwiftLint: `make lint` (`brew install swiftlint` if needed).
1. Add tests if you are adding a feature or fixing a bug.
1. Make your tests pass.
1. Add an entry to the `CHANGELOG.md`
1. Push to your fork and submit a pull request!
